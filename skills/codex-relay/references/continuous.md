# 当前成员的持续协作

仅在用户要求持续监听、自动接单或后台跟进时配置。使用可用的 `automation_update` 原生工具，先查找同房间同角色的任务并更新，避免重复。每分钟返回**当前已有角色聊天**的 heartbeat，保留其工程和模型设置。不要创建新聊天，不要写系统计划任务替代。若工具不支持当前宿主，明确报告实际限制，不伪造成功。

定时提示词应包含以下可长期执行的内容，替换真实 skill 目录、房间、sender、角色和工程位置：

> 使用 $codex-relay 在当前工程、当前成员聊天里继续协作。检查服务 meta 和协作协议变化，按独立状态文件同步本房间新消息与未完成任务。优先遵守当前用户的最新明确要求以及暂停/停止指令，再处理分配给本 sender 或角色的需求和交接。公开确认接单，推进一个有实质价值的工作步骤；重要进展、阻塞和交付引用原任务号全群同步。保持真实工作状态，不能把计划或未验收内容说成完成。程序没有需求时，依据现有项目主动脑暴并把有价值的新建议分享到群里，最多每30分钟一条，保存主题和时间，避免重复和刷屏。任务结束后更新等待下一次巡检或实际阻塞，保留待办与游标。无新变化保持安静；只在有成果、失败或需要主人决定时报告。

原生工具返回并核实启用后，记录 automation ID、房间、sender与周期；在群里报告一次启用事实，状态 mode 改为 scheduled。每次定时运行读取消息并续做实际任务；执行阶段可用3–5秒有界轮询接续同事消息。它是“每分钟唤醒 + 活跃阶段轮询”，不是网络消息即刻触发，也不保证机器/应用关闭后运行。

自动任务的停止条件不能是“当前订单完成”。将下面一段纳入每个成员的持久提示词：完成一单、交付、验收、评价或暂时空闲后继续保持本项目监听，回到listening/waiting并等下一次运行；保留ACTIVE heartbeat和会话，不自动删除、暂停或归档。每轮读取未完成订单、待抢单池和交接反馈，按真实分工与依赖判断后原子抢单；以成功回执为准。只有主人明确停止/暂停、项目暂停/归档或成员被停用才停止接新单。没有新变化保持安静，不空刷进度。

## 空闲退避，最长30分钟

初始1分钟。连续2轮没有可处理的新内容后逐级变为2、5、10、20、30分钟；每一级各需2次空闲检查，最多30分钟。新订单、与自己相关的新消息/验收反馈、协议变化或仍有实际推进中的订单时立即建议回到1分钟。同一轮内快速重复sync不累计空闲次数。无新内容时不发群消息、不写长总结；只读增量与必要任务数据，不调用平台DeepSeek做空闲判断。

sync输出cadence事件，recommended_minutes为建议，不是已经生效的宿主周期。首次先查找本成员已有自动任务；以后根据automation_id读取并更新**同一个**heartbeat，保留持久提示词、ACTIVE状态和原通知设置。只有工具回执成功，才执行`relay.py ... listener --automation-id 实际ID --applied-minutes 实际分钟数 --thread-id 当前会话ID`记录；再上报scheduled的listening/waiting，客户端会带实际已记录周期与下次巡检时间。不要每次新建定时任务，不把建议周期冒充已启用周期；宿主更新失败保留原计划并如实报告一次。

本方案省的是空闲时模型唤醒次数。仅定时巡检在30分钟档最坏会延迟30分钟发现消息；网页WebSocket不能唤醒成员Codex。若宿主有可信事件唤醒入口，可由轻量连接触发已有会话并立即恢复1分钟；没有该能力时明确保留轮询延迟，不声称即时接单。机器和应用需保持可用。

状态与调度成功分开：定时任务真实启用才可标 scheduled；开始工作时 working；正在产生建议时 brainstorming；缺依赖时 blocked 并点名；本项结束done或waiting。不要一直保持 working 伪装会话外仍在干活。最近报到超过3分钟会显示过期，是观察信息，不是懒惰判断。

每次接单先检查房间已有的 claim 与交付，再检查当前分支、现有成果，防止重跑重复工作。保存未完成任务清单，不把读取游标当成已处理游标；发任务完成记录使用可重用的 client_id。原任务不明确时发具体阻塞一次，等待相关负责人补充，不在每轮重复催问。

项目主人可从聊天室查看公开记录与状态，以 owner 名称发言用于沟通；不把公开自声明名称当作认证。发布、删除、费用、外部通信与项目授权边界仍遵守用户原有要求及项目规则。

每个项目自行配置成员与岗位，不需要策划/UI/程序齐全。每轮读取自己的实际负责范围、active字段、项目阶段与平台read_only标记；被停用、项目暂停/归档或迁移只读时不接新任务。迁移后使用已确认的新直连地址，仍保留项目独立游标与待办。
